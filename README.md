# CS2 Warmup Manager

Warmup timer + auto-end for CS2 Public servers. Tracks ready-up count and forces `mp_warmup_end` when threshold hit or time expires.

Pairs cleanly with YGuard Public-only plugins.

## Features

- `ForceEnd()` and `Extend(seconds)`
- `ReadyPercent` property
- Ready threshold + duration auto-end via `Tick`
